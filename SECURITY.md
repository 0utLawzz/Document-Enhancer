# Security Policy

## Reporting a Vulnerability

Please report security issues privately to **net2outlawzz@gmail.com** with the subject `[SECURITY] Document-Enhanser`.

Include a clear description, steps to reproduce, and potential impact. Do not open public issues for security vulnerabilities.

## Scope notes

Document Enhancer processes images entirely in the browser. No images are uploaded by the application itself. Maintain this privacy model when adding features.
